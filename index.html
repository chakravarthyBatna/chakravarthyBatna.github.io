About

I'm an Associate Development Engineer on the backend team at WaveMaker, a low-code platform companies use to build enterprise web and mobile apps. Most of my work is in authentication and security: identity providers, tokens, sessions, and secure integrations with GitHub.

The part of the job I enjoy most is debugging. I'm comfortable opening a large codebase I've never seen and following a problem until I understand exactly why it happens. In my free time I fix bugs in large open-source Java projects.

I'm also doing an MCA in AI and Machine Learning, and I build side projects with RAG and MCP to learn how AI fits into backend systems.

What I've built

SaaS to Enterprise migration platform

  • JavaScript
  • REST APIs
  • Docker
  • SQLite
Problem
Customers moving from WaveMaker Online to WaveMaker Enterprise had to move every app by hand.
What I built
An automated pipeline that orders imports by dependency across multi-level component hierarchies, follows branches, provisions roles, and can resume safely after a failure.
Result
100+ production apps and 800+ components migrated with zero data loss, and about 95% less manual work.

GitHub Apps integration

  • OAuth 2.0
  • GitHub Apps
  • Java
Problem
The platform reached customer repositories with long-lived personal access tokens.
What I built
A GitHub Apps integration with OAuth authorization, installation lifecycle handling, and short-lived tokens generated on demand.
Result
No long-lived credentials, and least-privilege repository access for enterprise GitHub organizations.

Multi-provider authentication

  • OpenID Connect
  • SAML
  • JWS
  • Spring Security
Problem
Customers needed different identity providers inside the same application.
What I built
A pluggable backend for token validation, sessions and identity resolution that supports OpenID Connect, SAML, JWS, opaque tokens and database login.
Result
One security model across all providers, and new providers can be added without platform changes.

Sign-in for embedded apps

  • JWS
  • SSO
  • Cross-origin
Problem
Browsers block Microsoft SSO when a WaveMaker app runs inside another site's iframe.
What I built
A signed-token exchange between the host page and the embedded app, with origin checks and signature verification.
Result
Users are signed in silently inside embedded apps, with no redirects.

Redis session store

  • MySQL
  • Spring

Result
About 45% lower authentication latency, and easier horizontal scaling for multi-tenant load.

How I work on a bug

  1. Reproduce it alone

    Strip the problem down to the smallest project that still fails.

  2. Find the root cause

    Read the source until the failure makes sense, not just the symptom.

  3. Make the smallest fix

    Change only what's needed and add tests that prove the bug is gone.

  4. Explain it clearly

    Write up the cause and the fix so reviewers can trust the change.
