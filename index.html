About

I'm a backend engineer at WaveMaker, a low-code platform that companies use to build enterprise web and mobile apps. I work on the Java and Spring Boot backend of the platform: building and maintaining backend features, REST APIs, and integrations that customers rely on.

The part of the job I enjoy most is debugging. I'm comfortable opening a large codebase I've never seen and following a problem until I understand exactly why it happens.

Right now I'm learning more about system design, building scalable REST APIs, and writing safe concurrent code in Java.

Open source

In my free time I contribute bug fixes to large open-source Java projects that many companies run in production. Maintainers review every change before it's merged.

How I work on a bug

  1. Reproduce it alone

    Strip the problem down to the smallest project that still fails.

  2. Find the root cause

    Read the source until the failure makes sense, not just the symptom.

  3. Make the smallest fix

    Change only what's needed and add tests that prove the bug is gone.

  4. Explain it clearly

    Write up the cause and the fix so reviewers can trust the change.
